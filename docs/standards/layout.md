# Layout

**Status: skeleton.** No rules are written here yet.

## Scope

Where things live in a CLI repository: the folders, the entry points, what the package exports, how large a file may
grow, and one job per file.

Rule ids on this page are `WC-LAY-<n>`. How to read a rule, how ids work and which rule wins are in the
[index](README.md).

## Rule template

```markdown
### WC-LAY-<n> · <the rule, in one short sentence>

- **Why:** <one line>.
- **Enforced by:** <check names in backticks, joined by " · ">, or the words "review only".
- **Example:** <a command or a piece of code that keeps the rule>.
- **Exceptions:** <when the rule does not apply>, or "none".
- **Applies to:** <all CLIs, or which ones>. **Since:** cli-base <version>. **Rulings:** <ids>, or "none".
```
