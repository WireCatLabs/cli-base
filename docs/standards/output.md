# Output

**Status: skeleton.** No rules are written here yet.

## Scope

What a command prints and how it fails: data on stdout and nothing else in machine mode, the envelopes, errors and
exit codes, partial answers, field projection and retries.

Rule ids on this page are `WC-OUT-<n>`. How to read a rule, how ids work and which rule wins are in the
[index](README.md).

## Rule template

```markdown
### WC-OUT-<n> · <the rule, in one short sentence>

- **Why:** <one line>.
- **Enforced by:** <check names in backticks, joined by " · ">, or the words "review only".
- **Example:** <a command or a piece of code that keeps the rule>.
- **Exceptions:** <when the rule does not apply>, or "none".
- **Applies to:** <all CLIs, or which ones>. **Since:** cli-base <version>. **Rulings:** <ids>, or "none".
```
