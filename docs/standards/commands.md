# Commands

**Status: skeleton.** No rules are written here yet.

## Scope

How a command is shaped: its path and the verb and resource words it uses, flags and arguments, the effects and
lifetime it declares, the entity it prints, the query language for lists, the `mcp` setting and help text.

Rule ids on this page are `WC-CMD-<n>`. How to read a rule, how ids work and which rule wins are in the
[index](README.md).

## Rule template

```markdown
### WC-CMD-<n> · <the rule, in one short sentence>

- **Why:** <one line>.
- **Enforced by:** <check names in backticks, joined by " · ">, or the words "review only".
- **Example:** <a command or a piece of code that keeps the rule>.
- **Exceptions:** <when the rule does not apply>, or "none".
- **Applies to:** <all CLIs, or which ones>. **Since:** cli-base <version>. **Rulings:** <ids>, or "none".
```
